# 企業控制權交付手冊

## 三種交付情境

| 情境 | 雲端帳號持有 | 開發者權限 | 做法 |
|---|---|---|---|
| A 完整交付 | 客戶 | 全部移除 | 於客戶帳號內部署 → 客戶自設 Secrets → 撤銷開發者成員身分 |
| B 完整交付＋維護 | 客戶 | 客戶授予、可隨時撤銷的成員角色 | 同 A，但保留受限成員；Secrets 由客戶持有 |
| C 開發者代管 | 開發者（專用帳號） | 全部 | 每客戶獨立 D1／Worker／Secrets，可整帳號移轉或匯出 D1 後在客戶帳號重新部署 |

## 交接步驟（A/B）

1. 客戶建立 Cloudflare 帳號，邀請開發者為成員（或開發者建立專用帳號後將 Super Administrator 轉給客戶）。
2. 在該帳號執行 `npm run provision -- --brand <brand>`。
3. 客戶自行取得並（透過 `.secrets` 檔或 `wrangler secret put`）設定 LINE、Threads、Gemini 憑證；**憑證持有方依合約寫明**。
4. 開發者交付：管理網址、管理員帳號（客戶首次登入即改密碼）、專案原始碼版本標籤、`docs/`、最新 D1 備份。
5. 客戶指派 LINE OA、Threads 帳號與 AI API 帳號的管理權（這些在各平台後台完成，系統無法代辦）。
6. 驗收（PRD 10.3）：
   - [ ] 客戶獨立登入後台並調整日常設定
   - [ ] 客戶取得 Cloudflare 控制權
   - [ ] 備份可成功還原到測試 D1
   - [ ] **開發者撤權後**，貼文排程、LINE 回覆、留資仍正常（實測）
   - [ ] 客戶選擇自行管理或委託維護

## 日常操作（客戶）

見後台：首頁看狀態／暫停；Threads 頁切換模式、審核草稿；LINE 頁改選單與 FAQ；留資頁標記處理。

## 客戶需知

- 免費額度用盡時系統會停止生成而非自動收費，但 Cloudflare／LINE／Gemini 方案升級需客戶自行決定。
- Threads token 約 60 天到期，需依警示更新（見 README 已知限制 3）。
- 放款相關內容的法遵責任在企業；系統只提供預設人工審核與基本禁用語檢查，不構成法律意見。
